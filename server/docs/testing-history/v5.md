# v5 test results

## Summary

`v5` is the OpenAPI verification suite.

Its purpose is to prove that the generated OpenAPI document exists and exposes the expected core API surface.

## Coverage

`v5` currently verifies:

- the generated document is OpenAPI `3.1.0`
- key route groups are present in the document
- security schemes for cookie auth are present

Latest verified result:

## Why v5 matters

`v5` gives a lightweight regression guard around the API contract presentation layer.

It proves that:

- the code-first OpenAPI document still generates
- the documented API surface has not disappeared accidentally
- the cookie-auth documentation remains wired into the spec
