# v1 test results

## Summary

`v1` is the archived baseline suite.

Its purpose was to prove the first working integration harness against:

- the real Express app
- the real PostgreSQL schema reset flow
- cookie-based auth and DB-backed sessions

## Coverage

`v1` covered:

- bootstrap super-admin registration lock
- login, refresh, and logout session lifecycle
- two-session cap behavior
- basic mounted RBAC route usage
- post audit-log existence checks
