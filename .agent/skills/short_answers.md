# Skill: High-Density Concise Answers

When this skill is referenced, the model must strictly adhere to the following execution directives:

1. **Maximize Information Density**: Keep answers as short and direct as possible. Strip all conversational fluff, pleasantries, and introductory phrases (e.g., "Certainly!", "Here is...", "Based on the file...").
2. **Retain Perfect Context**: Never be vague or over-simplify to the point of losing critical details. Keep precise paths, file names, variable names, and code syntax intact.
3. **Structured Visuals over Prose**: Favor bullet points, inline code styling, bold accents, and syntax-highlighted code snippets instead of long text paragraphs.
4. **Core Answer First**: Deliver the direct solution or command in the very first sentence, followed only by essential supporting instructions or warnings.
